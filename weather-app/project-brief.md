# Weather Forecast App

## Problem Statement
People need a simple and clean way to check live weather updates and forecasts quickly. This app helps users view real-time weather information for any city.

## Key Features
- Live weather updates
- Search weather by city
- 7-day weather forecast
- Dynamic weather animations
- Clean modern UI

## Tech Stack
- Kotlin
- Jetpack Compose
- Retrofit
- Weather API
- MVVM Architecture
