# Smart Expense Tracker

## Problem Statement
Many people struggle to track daily expenses and manage their monthly budget properly. This app helps users record expenses, monitor spending, and improve financial management.

## Key Features
- Add and manage expenses
- Monthly budget tracking
- Offline support
- Expense analytics and charts
- Clean and modern UI

## Tech Stack
- Kotlin
- Jetpack Compose
- Room Database
- Retrofit
- Hilt
- MVVM
- Clean Architecture
